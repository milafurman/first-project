## The first attempt was rejected, correctly

Mila: *"They look. The same"* — and she was right. Version 1 was two skins on one
layout: identical header, body, call-to-action and footer, with only the hero
strip differing. A variant, not a direction. Measured after the rebuild:

| | A | B |
|---|---|---|
| page | `#070D16` near-black | `#FFFFFF` |
| headline | 76px, weight 800 | 58px, **serif (Fraunces)**, weight 300 |
| the mark | full-bleed beside the headline | 94px circle, captioned |
| markup similarity | **17%** (was ~95%) | |

**A is a statement, B is a document.** Different typeface, colour logic, rhythm
and confidence — tellable apart from across the room, which was the whole point.

Visible-text similarity stays at 61% **on purpose**: both carry the same words so
only the look is being judged.

## Compliance, swept on both

No banned vocabulary, zero exclamation marks, exactly one research-use
disclaimer each, and all three load-bearing lines present in both — "Anyone can
fill a vial", the provenance line ("nothing more than that"), and the
human-or-veterinary scope.

## Known flaw in B

The hand photograph still carries the **old cap and old lizard** on the vial. If
B is chosen it needs re-rendering from the fixed master first. Flagged to Mila
rather than discovered later.
